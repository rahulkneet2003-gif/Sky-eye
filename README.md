## 📋 Overview

**SKY EYE** is a comprehensive, open-source intelligence (OSINT) platform designed for real-time geopolitical monitoring, threat assessment, and strategic intelligence analysis. Built as a single-page HTML5/CSS3/JavaScript application, it integrates live data streams from multiple intelligence sources to provide situational awareness across military, cyber, economic, space, and humanitarian domains.

The platform enables professionals, researchers, policy makers, and analysts to:

- ✅ **Monitor global conflicts** — 43+ active conflict zones, real-time escalation tracking
- ✅ **Track military posture** — 9,000+ military installations, naval assets, carrier strike groups
- ✅ **Cyber threat intelligence** — APT tracking, CVE monitoring, dark web analysis
- ✅ **Space domain awareness** — Satellite launches, LEO debris tracking, space militarization
- ✅ **Economic warfare** — Sanctions tracking, crypto evasion, financial weaponization
- ✅ **Aviation & maritime** — ADS-B tracking, 93,000+ vessels monitored, naval operations
- ✅ **Nuclear intelligence** — 12,500+ warheads catalogued, IAEA alerts, proliferation risk
- ✅ **AI-assisted analysis** — Automated threat assessment, risk forecasting, report generation

## 🚀 Quick Start

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/rahulkneet2003-gif/Sky-eye.git
cd Sky-eye
```

2. **Open in browser**
```bash
# Method 1: Direct file
open index.html

# Method 2: Local server (Python 3)
python3 -m http.server 8000
# Navigate to http://localhost:8000

# Method 3: Local server (Node.js)
npx http-server
```

3. **Configure AI Analysis (Optional)**
   - Add Claude API key in settings for AI-assisted report generation
   - Without API key, platform runs in offline/simulation mode
   - All data feeds operate independently of API integration

### First Steps
1. 🌍 Start with **3D Globe** for global overview
2. 📊 Check **Global Threat Dashboard** for current metrics
3. 🎯 Select a region in **Conflict Intelligence** for detailed analysis
4. 🛰️ Monitor **Space Domain** for satellite activity
5. 📋 Review **Watch Officer Log** for event tracking

- Integration of additional intelligence APIs
- Modification of dashboard layouts & visualizations
- Deployment to any static hosting platform
- Real-time data stream configuration

### API Integration
To add new intelligence sources:

```javascript
// Example: Adding a new threat feed
fetch('https://api.threatintel.com/feeds')
  .then(response => response.json())
  .then(data => {
    // Process and integrate into threat dashboard
    updateThreatMetrics(data);
  })
  .catch(error => console.error('Feed error:', error));
```
